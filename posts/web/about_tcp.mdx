## 전송 계층

TCP에 관해서 이야기 한다 했으면서 어째서 제목을 TCP가 아니라 전송 계층이라고 표현 했을까요? 이에 대해서는 앞서 설명한 네트워크 계층 때문입니다. 앞서 네트워크 계층은 `클라이언트 -> 응용계층 -> 전송계층 -> 네트워크 계층 -> 데이터 링크 계층 -> 물리 계층`으로 구성이 되어 있다고 설명했었습니다.
